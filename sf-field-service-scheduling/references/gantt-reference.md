# Dispatcher Console / Gantt Chart Reference

## Architecture

The FSL Dispatcher Console is a Visualforce page (`FSL__DispatcherConsole`) hosting a JavaScript single-page application. It runs in the FSL managed package namespace and communicates with the server via Apex remoting.

| Component | Description |
|-----------|-------------|
| VF Page | `FSL__DispatcherConsole` — container page |
| JS App | Managed JS bundle in FSL namespace, renders the Gantt |
| Data Source | Apex remoting to FSL managed Apex classes |
| Namespace | All objects/fields prefixed with `FSL__` |

---

## Display Elements

### Service Appointment Blocks

- Displayed as horizontal bars on the resource's row.
- Width proportional to duration.
- Position corresponds to `SchedStartTime` and `SchedEndTime`.
- Travel time shown as a shaded extension before the block (if enabled).

### Resource Absences

- `ResourceAbsence` records displayed as blocked-out regions on the resource's row.
- Configured via `FSL__Absence_Type__c` for visual styling.
- Types: Vacation, Sick, Training, Break, etc.

### Travel Time

- Shown as a gray/shaded bar preceding each SA block.
- Calculated from previous appointment or home base.
- Only visible if travel calculation is enabled.

### Breaks

- `ResourceAbsence` records of type Break.
- Displayed inline on the resource row.
- Can be auto-generated by scheduling optimization.

### Operating Hours

- Non-operating hours shown as grayed-out background.
- Derived from `OperatingHours` on the `ServiceTerritory`.

### Shifts

- `Shift` records displayed as available windows on the resource row.
- When shift-based scheduling is enabled, SAs can only be placed within shift windows.

## Color Coding

### Configuration

Colors are configured via **Gantt Palettes** (FSL__Gantt_Palette__c):

| Field | Description |
|-------|-------------|
| `FSL__Color__c` | Hex color code |
| `FSL__Field__c` | Field on SA that determines color (e.g., `Status`, `FSL__GanttColor__c`) |
| `FSL__Value__c` | Field value that triggers this color |

### Default Status Colors

| Status | Default Color | Hex |
|--------|--------------|-----|
| None | Light Blue | `#A8D8EA` |
| Scheduled | Blue | `#4A90D9` |
| Dispatched | Orange | `#F5A623` |
| In Progress | Green | `#7ED321` |
| Completed | Dark Green | `#417505` |
| Canceled | Red | `#D0021B` |
| Cannot Complete | Gray | `#9B9B9B` |

### Custom Color Field

Use `FSL__GanttColor__c` (formula or custom field) on ServiceAppointment to set per-record colors dynamically.

## Drag-and-Drop Actions

| Action | Behavior |
|--------|----------|
| Drag SA to a resource row | Reschedules to that resource at the drop position time |
| Drag SA horizontally | Changes scheduled time, keeps same resource |
| Drag SA to unscheduled area | Unschedules the appointment |
| Drag from unscheduled list | Schedules the SA to the target resource/time |

### Validation on Drop

- Work rules are evaluated on drop. If rules fail, the Gantt shows a warning and may prevent the action.
- Configurable: `FSL__Scheduling_Policy__c.FSL__Fix_Overlaps__c` determines if overlaps are auto-resolved.

## Global Actions

Accessible from the Gantt toolbar. Apply to all visible or selected appointments.

### Schedule

- **Scope:** Selected unscheduled SAs or all unscheduled in the territory.
- **Behavior:** Runs the scheduling engine using the active scheduling policy.
- **Does not move** already-scheduled or pinned SAs.

### Optimize

- **Scope:** All scheduled (non-pinned) SAs in the visible time range and territory.
- **Behavior:** Reshuffles appointments to improve objective scores (minimize travel, balance workload, etc.).
- **Respects:** Pinned appointments, resource absences, operating hours.
- **Duration:** Can take seconds to minutes depending on volume.

### Unschedule

- **Scope:** Selected SAs.
- **Behavior:** Clears scheduling fields. SAs return to the unscheduled list.

## Custom Actions

Custom actions extend the Gantt with org-specific functionality.

### Object: `FSL__Custom_Action__c`

| Field | Description |
|-------|-------------|
| `FSL__Action_Type__c` | `Appointment`, `Resource`, `Global` |
| `FSL__Apex_Class__c` | Apex class implementing `FSL.CustomGanttAction` |
| `FSL__Label__c` | Display label in the menu |
| `FSL__Icon__c` | SLDS icon name |
| `FSL__Sort_Order__c` | Position in the menu |
| `FSL__Active__c` | Enable/disable |

### Interface

```apex
global interface CustomGanttAction {
    void execute(Map<String, Object> params);
}
```

### Parameters Map Keys

| Key | Type | Context |
|-----|------|---------|
| `serviceAppointmentId` | Id | Appointment actions |
| `serviceResourceId` | Id | Resource actions |
| `start` | DateTime | Selected time range |
| `end` | DateTime | Selected time range |

## Filters

### Resource Filters

| Filter | Description |
|--------|-------------|
| Territory | Show resources from selected territories |
| Skill | Filter resources by skill |
| Active | Show only active resources |
| Crew | Filter by crew membership |

### Appointment Filters

| Filter | Description |
|--------|-------------|
| Status | Filter by SA status |
| Priority | Filter by priority |
| Work Type | Filter by WorkType |
| Scheduled/Unscheduled | Toggle visibility |
| Violation | Show only SAs with scheduling violations |
| In Jeopardy | Show SAs at risk |

### Territory Filters

- Multi-select territory picker in the header.
- Changing territory reloads resources and appointments.
- Supports territory hierarchy — selecting a parent includes children.

### Skill Filters

- Filter the resource list to only show resources with specific skills.
- Useful when dispatching specialized work.

## Views

### Long Day View

| Property | Value |
|----------|-------|
| Time range | Single day |
| Granularity | 15-minute, 30-minute, or 1-hour intervals |
| Best for | Detailed daily dispatching, same-day scheduling |
| Shows | Full timeline with travel, breaks, and gaps clearly visible |

### Multi-Day View

| Property | Value |
|----------|-------|
| Time range | 2-14 days (configurable) |
| Granularity | Coarser — SA blocks are compressed |
| Best for | Weekly planning, capacity overview, identifying gaps |
| Shows | High-level workload distribution |

### Switching Views

Toggle between views using the view selector in the Gantt toolbar. The time range selector controls the number of days in Multi-Day View.

## Gantt Customization

### Palettes

Configure via **Field Service Settings > Dispatcher Console > Gantt Configurations**.

| Setting | Description |
|---------|-------------|
| Color Palette | Map field values to colors |
| Secondary Color | Status-based border or accent colors |
| Tooltip Fields | Fields shown on hover (via field sets) |

### Field Sets

| Field Set | Object | Purpose |
|-----------|--------|---------|
| `FSL__Gantt_Tooltip` | ServiceAppointment | Fields shown on SA hover tooltip |
| `FSL__Gantt_Tooltip` | ResourceAbsence | Fields shown on absence hover tooltip |
| `FSL__Appointment_List` | ServiceAppointment | Columns in the unscheduled appointment list |

### Drip Feed

Drip feed controls how unscheduled appointments are released to dispatchers.

| Setting | Description |
|---------|-------------|
| `FSL__Drip_Feed__c` | Enable drip feed on the policy |
| Drip Feed Horizon | Time window ahead that appointments become visible |
| Purpose | Prevent dispatchers from seeing the full backlog; focus on near-term work |

- When enabled, only SAs within the drip feed horizon appear in the unscheduled list.
- Horizon is typically 1-3 days ahead.
- SAs outside the horizon are hidden from the Gantt but still exist in the system.

## Optimization Scope Configuration

### What Gets Optimized

| Setting | Description |
|---------|-------------|
| Territories | Only SAs in selected territories |
| Time Range | Only SAs within the Gantt's visible date range |
| Pinned SAs | **Excluded** — pinned SAs remain fixed |
| Locked Statuses | SAs in certain statuses (Dispatched, In Progress, Completed) are not moved |
| Resource Absences | Respected as hard constraints |

### Optimization vs. Scheduling

| Action | What It Does |
|--------|-------------|
| **Schedule** | Assigns unscheduled SAs to resources/times. Does not move existing. |
| **Optimize** | Reshuffles already-scheduled SAs to improve objective scores. |
| **Schedule + Optimize** | Both — schedule new work, then optimize the full picture. |

### Optimization Controls

| Control | Description |
|---------|-------------|
| `FSL__Pinned__c` | Boolean on SA. If true, optimization will not move this SA. |
| `FSL__InJeopardyReason__c` | Flags why an SA is at risk. Informational, not a hard constraint. |
| Locked Statuses | Configured in FSL Settings. Typically: Dispatched, In Progress, Completed, Cannot Complete. |
| Optimization Request | `FSL__Optimization_Request__c` — tracks async optimization jobs. |

### Optimization Best Practices

- Pin customer-confirmed appointments.
- Lock statuses for in-flight work.
- Run optimization during off-hours for large territories (it can take minutes).
- Test optimization in a sandbox before production. Results depend heavily on objective weights.
- Monitor `FSL__Optimization_Request__c` for job status and errors.
